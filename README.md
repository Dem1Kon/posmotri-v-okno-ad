# Посмотри в окно
Проектная работа Яндекс Практикума по вёрстке интерфейса поиска видео.
В проекте реализована страница с видеоплеером, формой поиска и списком видео. Стили адаптируются для узких экранов.
## Запуск
Откройте файл `index.html` в браузере.
